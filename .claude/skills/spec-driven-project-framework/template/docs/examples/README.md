# About these examples

The files here are one complete, filled-in document set for a small photo-club app. They show the level of detail each document needs — they are **not** this project's design and not text to copy.

They were written for a team working on a weekly schedule, so you'll see "Week N" and an instructor as the sponsor. Read them with this mapping:

| In the examples | In your project |
|---|---|
| Weeks 1–2 | Frame and Specify phases |
| Weeks 3–4 | Design phase (Plan, Data & API Design) |
| Week 5 | Task phase |
| Week 6 | Validation build |
| Week 7 | Fix phase and re-run |
| Week 8 | Final build |
| Instructor / "Weekly Status" | Sponsor or reviewer / `STATUS.md` |
| Vue app, `data.js`, Supabase | Whatever ADR-00 chooses; `data.js` stands for the data-access module |
