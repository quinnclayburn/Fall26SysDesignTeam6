# Club Photos — Business Case

> **Example.** This is a filled-in version of `business-case.md` for the photo-club app. Use it to see the level of detail expected — not as text to copy.
>
> **Sponsor decision:** Go · **By:** Dr. Morgan (instructor) · **Date:** 2026-09-11

---

## 1. Problem

**Who is affected?** The photography club's 40 members and the 2 admins who run events.

**What's wrong today?** Event photos are shared over group text, which lowers their quality and buries older photos within days.

**How will we know it worked?** Within a month of launch, 70% of members have viewed the gallery after an event, and admins stop posting photos to the group text.

---

## 2. Proposed Solution

A simple, members-only website where admins upload each event's photos at full quality, and members can browse them by event at any time.

---

## 3. Options Considered

| Option | Description | Pros | Cons |
|--------|-------------|------|------|
| Do nothing | Keep sharing over group text | No cost, no effort | Photos lose quality and get lost |
| Option A | Shared albums in a free photo app | Fast to set up, free | Hard to keep members-only; albums get scattered across accounts |
| **Option B (recommended)** | Build a small members-only web app | Full quality, organized by event, members-only | Takes build time |

---

## 4. Can We, and Is It Worth It?

| Question | Answer |
|----------|--------|
| **Will people actually use it?** | Yes — members already ask each other for event photos; this gives them one place to look. |
| **Can we build it with what we have?** | Yes — two teammates have built web apps, and free hosted services can handle login and file storage. |
| **Can it be done in time to matter?** | Yes — a basic version can be ready before the November exhibition. |
| **What does it cost?** | About 40 volunteer hours to build. Hosting and storage are $0 on the free tier, or up to $60 a year if we outgrow it. |
| **What do we gain?** | About 2 hours saved per event collecting and resending photos (measurable); photos kept at full quality (measurable: original files, no compression); more members engaging with club events (real, but hard to measure). |

---

## 5. Recommendation

Approve Option B: build a members-only photo app this term, with browsing and uploading ready before the November exhibition — the club's biggest event. If it isn't ready, those photos end up lost in the group text for another year.
